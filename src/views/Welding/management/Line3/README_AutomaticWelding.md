# 自动焊产能组件说明

## 概述

本目录包含两个自动焊产能组件，用于展示和管理自动焊1线和2线的当日小时产能数据。

## 组件列表

### 1. 自动焊1线产能组件 (`oneProdLine.vue`)
- **功能**: 展示自动焊1线24小时产能趋势
- **数据源**: `getAutomaticWelding('HJ1')`
- **填写接口**: `automaticWeldingFillin` (code: 'HJ1')

### 2. 自动焊2线产能组件 (`twoProdLine.vue`)
- **功能**: 展示自动焊2线24小时产能趋势
- **数据源**: `getAutomaticWelding('HJ2')`
- **填写接口**: `automaticWeldingFillin` (code: 'HJ2')

## 主要特性

### 📊 数据展示
- **折线图**: 24小时产能趋势图，分别显示车架、后叉、尾架的产能变化
- **汇总数据**: 显示当日总产能数据
- **实时更新**: 数据填写后自动刷新图表

### ✏️ 数据填写
- **24小时输入**: 每个小时可分别输入车架、后叉、尾架的产能
- **批量提交**: 一次性提交24小时的所有数据
- **数据验证**: 输入框限制最小值为0

### 🎨 界面设计
- **响应式布局**: 自适应容器大小
- **渐变主题**: 绿色渐变标题栏
- **交互反馈**: 悬停效果和加载状态

## API接口

### 获取产能数据
```typescript
getAutomaticWelding(code: string): Promise<{data: AutomaticWelding}>
```
- `code`: 'HJ1' (自动焊1线) 或 'HJ2' (自动焊2线)

### 填写产能数据
```typescript
automaticWeldingFillin(data: AutomaticWeldingFillin): Promise<any>
```

**数据结构**:
```typescript
interface AutomaticWeldingFillin {
  code: string // 'HJ1' 或 'HJ2'
  hourList: {
    hour: number // 小时 (1-24)
    cj: number   // 车架产能
    hch: number  // 后叉产能
    wj: number   // 尾架产能
  }[]
}
```

## 使用说明

### 1. 查看产能趋势
- 组件加载后自动显示24小时产能折线图
- 图表显示车架(蓝色)、后叉(绿色)、尾架(橙色)三条趋势线
- 底部显示当日总产能汇总

### 2. 填写产能数据
- 点击"填写产能"按钮打开填写对话框
- 在24小时输入网格中填写各部件产能
- 点击"提交"保存数据，系统会自动刷新图表

### 3. 数据管理
- 每次提交会覆盖原有的24小时数据
- 建议在填写前先查看现有数据
- 支持部分小时数据填写，未填写的默认为0

## 技术实现

### 依赖库
- **Vue 3**: 组合式API
- **ECharts**: 图表渲染
- **Element Plus**: UI组件库
- **TypeScript**: 类型安全

### 核心功能
- **响应式数据**: 使用Vue 3的ref和computed
- **图表管理**: ECharts实例的生命周期管理
- **异步操作**: API调用和错误处理
- **组件通信**: 父子组件数据传递

## 注意事项

1. **数据完整性**: 每次提交需要包含完整的24小时数据
2. **API兼容性**: 当前版本假设后端返回的数据结构包含hourList
3. **错误处理**: 网络错误和API错误都有相应的用户提示
4. **性能优化**: 图表更新使用防抖处理，避免频繁重绘
