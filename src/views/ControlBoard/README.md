# 中控大屏看板系统

## 功能概述

这是一个专为浙江阿波罗运动科技股份有限公司设计的中控大屏看板系统，具有以下特色功能：

### 🎯 核心特性
- **炫酷的Three.js地球模型** - 中央展示3D地球，体现全球摩托车贸易业务
- **实时数据监控** - 动态显示订单、生产、设备等关键指标
- **响应式设计** - 支持多种屏幕尺寸，适配不同显示设备
- **现代化UI** - 采用深色主题，具有科技感和专业性

### 🌍 地球模型特色
- 3D地球自转动画
- 云层环绕效果
- 摩托车模型展示
- 星空背景
- 动态光照效果

### 📊 数据展示模块
1. **顶部数据卡片**
   - 今日订单数量
   - 生产进度百分比
   - 设备运行状态
   - 库存预警信息

2. **左侧图表区域**
   - 月度销售趋势图
   - 生产线状态监控

3. **右侧状态区域**
   - 全球市场分布饼图
   - 设备运行状态详情

4. **底部进度条**
   - 订单完成率
   - 质量合格率
   - 交付及时率
   - 客户满意度

## 技术架构

### 前端技术栈
- **Vue 3** - 现代化前端框架
- **TypeScript** - 类型安全的JavaScript
- **Three.js** - 3D图形渲染库
- **Tailwind CSS** - 实用优先的CSS框架
- **Vite** - 快速构建工具

### 组件结构
```
ControlBoard/
├── index.vue              # 主看板组件
└── components/
    ├── DataCard.vue       # 数据卡片组件
    ├── EarthModel.vue     # 3D地球模型组件
    ├── ChartCard.vue      # 图表卡片组件
    ├── ProgressCard.vue   # 进度卡片组件
    ├── StatusCard.vue     # 状态卡片组件
    └── ProgressBar.vue    # 进度条组件
```

## 使用方法

### 1. 访问看板
在浏览器中访问对应的路由地址，看板会自动加载并显示。

### 2. 数据更新
- 看板支持实时数据更新（每5秒自动刷新部分数据）
- 可以点击图表上的刷新按钮手动更新数据
- 支持全屏模式查看详细数据

### 3. 交互功能
- 鼠标悬停查看详细信息
- 点击设备状态可查看详情
- 支持图表全屏显示

## 自定义配置

### 修改数据源
在 `index.vue` 中修改相应的响应式数据：

```typescript
// 修改业务数据
const todayOrders = ref(156)
const productionProgress = ref(87)
// ... 其他数据
```

### 调整样式主题
在组件的 `<style>` 部分修改颜色和样式：

```css
/* 修改主题色 */
:root {
  --primary-color: #00ffff;
  --success-color: #00ff96;
  --warning-color: #ff9600;
  --danger-color: #ff0066;
}
```

### 添加新的数据指标
1. 在 `index.vue` 中添加新的响应式数据
2. 创建对应的展示组件
3. 在模板中引入并使用

## 性能优化

### 3D渲染优化
- 使用 `requestAnimationFrame` 进行动画循环
- 合理设置几何体精度
- 及时清理Three.js资源

### 数据更新优化
- 使用防抖处理频繁的数据更新
- 合理设置定时器间隔
- 避免不必要的DOM操作

## 注意事项

1. **Three.js依赖** - 确保项目中已安装Three.js
2. **性能监控** - 在低性能设备上可能需要调整3D渲染质量
3. **数据安全** - 生产环境中请使用真实的后端API数据
4. **响应式适配** - 建议在不同尺寸的屏幕上测试显示效果
