# 🌍 阿波罗中控大屏 - 地球模型功能说明

## 地球模型概述

现在的地球模型已经升级为一个**真实的3D地球**，具有以下特色功能：

### 🎯 核心特性

#### 1. **真实地球纹理**
- 使用Canvas绘制的地球贴图
- 包含大陆轮廓（亚洲、欧洲、非洲、北美洲、南美洲、澳大利亚）
- 海洋背景（蓝色）
- 陆地细节（棕色和绿色）
- 极地冰盖（白色）

#### 2. **贸易飞线图** ✨ **新功能**
- **杭州 → 纽约**：红色飞线，贸易强度 0.8
- **杭州 → 伦敦**：青色飞线，贸易强度 0.6

#### 3. **城市标记系统**
- **杭州**：总部城市，金色标记，尺寸最大
- **纽约**：北美贸易中心
- **伦敦**：欧洲贸易中心
- **东京**：亚洲贸易中心
- **悉尼**：大洋洲贸易中心
- **圣保罗**：南美贸易中心

#### 4. **动态视觉效果**
- 飞线光点沿路线移动
- 城市标记闪烁效果
- 地球自转动画
- 云层环绕效果
- 大气层光晕

#### 5. **地球网格系统**
- 经线（子午线）：12条
- 纬线（平行线）：8条
- 半透明网格线，增强地理感

## 技术实现

### 坐标转换
```javascript
// 经纬度转换为3D坐标
const latLngToVector3 = (lat, lng, radius) => {
  const phi = (90 - lat) * (Math.PI / 180)
  const theta = (lng + 180) * (Math.PI / 180)
  
  const x = -(radius * Math.sin(phi) * Math.cos(theta))
  const z = (radius * Math.sin(phi) * Math.sin(theta))
  const y = (radius * Math.cos(phi))
  
  return new THREE.Vector3(x, y, z)
}
```

### 飞线动画
- 使用贝塞尔曲线创建平滑的飞线路径
- 光点沿曲线移动，模拟数据流动
- 不同颜色代表不同的贸易路线
- 动态透明度变化，增强视觉效果

### 性能优化
- 使用 `requestAnimationFrame` 进行动画循环
- 适当的几何体细分（64x64）
- 资源清理和内存管理
- 响应式设计，支持窗口大小调整

## 视觉效果说明

### 为什么这样设计？

1. **象征意义**：地球代表阿波罗公司的全球业务范围
2. **数据可视化**：飞线直观展示贸易流向和强度
3. **地理定位**：城市标记帮助用户理解业务分布
4. **动态交互**：动画效果增强用户体验和视觉吸引力

### 颜色含义
- 🔴 **红色**：高价值贸易路线
- 🔵 **蓝色**：主要贸易伙伴
- 🟢 **绿色**：新兴市场
- 🟡 **黄色**：发展中的贸易关系
- 🟣 **青色**：传统贸易伙伴
