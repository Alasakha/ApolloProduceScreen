# 🌍 阿波罗中控大屏 - 高级3D地球模型

## 🎯 模型概述

这是一个基于专业Three.js案例的**高级3D地球可视化系统**，整合了多个高级特效，实现了接近商业级3D软件的效果。

### ✨ 核心特性

#### 1. **专业级地球模型**
- **高精度几何体**：128x128细分球体，50单位半径
- **程序化纹理**：1024x512分辨率，包含大陆、海洋、极地冰盖
- **真实光照**：Phong材质，高光反射，阴影渲染
- **透明背景**：支持透明背景，完美融入现有UI

#### 2. **星空背景系统**
- **10000颗星星**：随机位置、大小、颜色
- **动态星空**：星星缓慢移动，营造宇宙感
- **高级混合**：AdditiveBlending混合模式
- **性能优化**：BufferGeometry，GPU加速

#### 3. **月球系统**
- **月球模型**：2单位半径，发光材质
- **月球轨道**：半径65单位，绕地球公转
- **轨道环**：半透明环形，增强视觉效果
- **动态运动**：实时计算月球位置

#### 4. **光柱特效**
- **30个光柱**：随机分布在地球表面
- **交叉光柱**：X形光柱，增强立体感
- **波纹扩散**：GSAP动画，波纹缩放效果
- **随机延迟**：错开动画时间，自然效果

#### 5. **贸易飞线系统**
- **5条贸易路线**：杭州到全球主要城市
- **贝塞尔曲线**：100个点的平滑飞线
- **动态光点**：沿飞线移动的光点
- **颜色编码**：不同颜色代表贸易强度

#### 6. **城市标记系统**
- **6个主要城市**：杭州、纽约、伦敦、东京、悉尼、圣保罗
- **金色标记**：高亮显示重要城市
- **光晕效果**：发光光晕，增强视觉效果
- **尺寸分级**：根据重要性设置不同尺寸

#### 7. **交互控制系统**
- **OrbitControls**：鼠标拖拽、缩放、旋转
- **阻尼效果**：平滑的相机运动
- **响应式设计**：自动适配窗口大小
- **性能优化**：60FPS流畅动画

1. **降低分辨率**：在低端设备上降低纹理分辨率
